## 归档规则（agent 共同维护）

1. 做出被先生明确点赞的卡片 → 整卡复制进本目录（文件名用卡片主题）。
2. 提炼 1~3 条「为什么好看」的技法，写入对应 `styles/<slug>.md` 的【点睛技法】（已有同款则不重复）。
3. 无对应风格文档 → 按 `styles/_BASELINE.md` 的骨架约定新建风格文档，并在 styles/_INDEX.md 追加一行。
4. 本清单同步补一行。
